# Trampolin – gemt 2D-version

En spilbar kopi af 2D-udgaven (Neon og Klubhallen), som den var, før spillet gik over til 3D.
Spil den på https://larstowt.github.io/-mt/2d/ – samme version findes også i git som mærket `trampolin-2d-v1`.

Kopien har sin egen service worker og cache (`trampolin2d-…`), så den kan installeres og spilles offline ved siden af hovedversionen.
Gemte rekorder deles med hovedversionen, fordi de ligger på samme adresse.
